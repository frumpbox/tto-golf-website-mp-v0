# Roadmap

Last verified: 6 August 2026

This is a lightweight sequencing guide, not a fixed delivery schedule.

## Now — Documentation and current-state validation

- Establish and maintain the focused documentation foundation.
- Confirm source-of-truth boundaries before feature work.
- Keep current build, preview, data, and content status recorded accurately.
- Preserve the Vite static multi-page architecture.

## Next — Data and content foundations

- Preserve the reviewed historical leaderboard values and continue resolving
  missing source material only as separately approved work.
- Confirm missing leaderboard gross scores and handicap indexes from
  authoritative information.
- Maintain the annual renderer against the verified consolidated data model.
- Maintain the validated Course Ratings workbook import and normalized
  hole-tier schema.
- Populate Year in Review articles and galleries as approved content becomes
  available.

Year in Review is **implemented but partially populated**. It is not a new
feature build.

## Later — Focused feature improvements

- Continue reviewing overall rankings as unresolved annual positions are verified.
- Improve Course Ratings presentation after data normalization.
- Continue general visual, responsive, semantic, and accessibility polish.
- Replace About and Shop placeholders when real content is available.
- Reduce repeated page-shell maintenance if it can be done without changing
  the framework model or public URLs.

## Paused — Separate Frumpbox stream

- Frumpbox integration and automation.
- Discord-driven development workflows.
- Cross-project workspace migration.
- Automated publication.

Frumpbox work is separate from the critical path for improving TTO.

## Current status summary

- Documentation foundation: **Now**
- Current-state validation: **Now**
- Year in Review: **Implemented / partially populated**
- Leaderboard migration data: **In progress / not verified**
- Course Ratings: **Implemented / authoritative subjective ratings imported and normalized**
- General website polish: **Later**
- Frumpbox integration: **Paused / separate stream**
