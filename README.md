# The Tyrrells Open

The Tyrrells Open (TTO) is an annual golf competition. This website records
its competitors, results, courses, course ratings, and stories from each
edition of the event.

The site is a Vite static multi-page website built with plain HTML, CSS, and
JavaScript. It is not a single-page application and does not use a frontend
framework.

## Local development

```bash
npm install
npm run dev
npm run build
npm run preview
```

- `npm run dev` starts the Vite development server.
- `npm run build` creates a production build in `dist/`.
- `npm run preview` serves the production build locally.

## Pages

- `index.html` — Home
- `about.html` — About Us
- `leaderboard.html` — Leaderboard
- `course-ratings.html` — Course Ratings
- `year-in-review.html` — Year in Review
- `shop.html` — Shop
